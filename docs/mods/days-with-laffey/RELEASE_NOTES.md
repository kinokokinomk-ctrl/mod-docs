# Days with Laffey -ラフィーと一緒- [Azur Lane]｜今後のアップデート予定

ラフィーとの生活をもっと楽しめるよう、外見・日常・交流・戦闘などの要素を今後も充実させていく予定です。

> 以下は**構想・開発予定**であり、現時点で実装済みの機能ではありません。内容や順番は変わる場合があります。

## 次回の予定 — ラフィーちゃんロングヘア化計画

- 長い髪型をより自然に表示できるようにします。
- **短めの髪／ロングヘア**を選んで切り替えられるようにします。
- 現在の通常衣装を改善し、新しい衣装も追加する予定です。

## 今後の構想（順不同）

- **外見・日常：** 追加衣装、外見バリエーション、グラフィック改修、ちょっとした小ネタ。
- **交流：** ラフィーとの交流イベント、好感度システム。
- **冒険：** 専用の派生クエスト。
- **成長：** 研究ツリーと改造システムの大型拡張。「改＋Ⅱ」や、他艦船のスキルを疑似的に使用できる装備など。
- **戦闘：** 操作性の向上、スキルの調整。
