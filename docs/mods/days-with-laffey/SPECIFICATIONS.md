## 概要

- 名称：**Days with Laffey -ラフィーと一緒- [Azur Lane]**
- 今回のテーマ：**Face Animation Plus**（2026-11-05 Steam Workshop更新済み）
- 内容：『アズールレーン』のラフィーをRimWorldへ迎える非公式・非営利ファンMOD。日常、独自表情、専用装備と戦闘スキルを実装。
- 作者：ラフィーの指揮官。Workshop ID：**3819030381**／[公開ページ](https://steamcommunity.com/sharedfiles/filedetails/?id=3819030381)。
- 公開告知は**v0.7.24**。配布済み`About.xml`内の`modVersion`は**`0.7.24-dev`**のまま（表記差）。
- MOD内の`About/Preview.png`とWorkshop掲載画像を、新しい「Face Animation Plus」画像に差し替え。

### ビルド・配布

- 1.6は**.NET Framework 4.7.2**／RimRef `1.6.4871`／Harmony `2.4.3`。1.7は**.NET 10**／RimRef `1.7.4985-unstable`／Harmony `3.0.0-rc.3`。
- `Build-UniqueArrival.cmd`／`Build-Both.cmd`でNuGet参照を使い**1.6・1.7のDLLを一括独立ビルド**。ゲームインストール版の切替不要。日本語パスを避けるためASCII名の一時作業フォルダへソースをコピーする。
- 1.7テスト本体は`1.7.4998 rev1299`。参照パッケージは少し古いため、ビルド成功だけで全機能互換は保証されない。
- 公開用パッケージは**両方のビルド済みDLL入り**。Source、ビルドCMD、PDB、ログはWorkshop配布ZIPから除外した。

## 機能・ゲーム内仕様

### 登場・外見

- ゲーム開始後**1〜3日目**に加入イベントが発生。登場しなければ3日経過後に通信機またはMOD設定から呼び出せる。
- 固有の出自、能力、性格、専用の顔と**切替可能な髪型2種**を持つ。
- 初期服「ラフィー通常衣装」は他入植者も着用可能。布Tシャツ・布ズボンとともに加入時支給。防御の基準はバニラ防弾ジャケット相当で、衣装由来の移動速度低下はない。
- v0.7.24で衣装の**耐寒・耐暑・真空耐性**を強化、背面時の首元の浮きを修正。

### 表情アニメーション（Face Animation Plus）

- 独立した顔パーツ・表情：通常の瞬き、戦闘、睡眠、研究、ダウン、痛み、食事、恋愛・頬染めなど。
- **正面向きの食事中**は口の上下アニメーション。横向き口の視認性と戦闘時眉毛の位置も調整。
- **Facial Animationは必須ではない**。導入時も独自表情を維持。MOD設定から動きをON／OFF可能。

### 専用装備・戦闘スキル

- **127mm単装砲**：固定武装、長射程爆発弾。狩猟中は自動で非爆発弾に切替。淡いピンクの曳光、命中計算・移動標的への命中処理を調整。
- **533mm五連装魚雷**：手動。5発を扇状に発射し、壁越し運用を考慮してラフィーの前方から出現。
- **殲滅形態**：手動。主砲を**0.2秒間隔で10連射**し、魚雷5発も発射（魚雷は発動約0.5秒後、再使用時間120秒。魚雷挙動は従来どおり）。
- **射線確保**：手動の高速移動で射撃位置を確保。
- **ソロモンの戦神**：主砲攻撃時に確率発動し、射撃速度を向上させる自動能力。
- 攻撃は必中ではなく、爆発弾・魚雷で味方や建築物を巻き込むことがある。バニラを意識したバランス。

### 日常・撤退・任意連携

- 専用特性「おねむ」「マイペース」「仲間思い」、昼寝、救助・戦闘に応じた固有心情。通常入植者同様に仕事と社交を行う。
- 左下の行動表示は**瞑想・睡眠・食事・研究・掃除・建築・採掘・種まき・収穫**の9種類で専用のひとことに変更。睡眠例「ムニャムニャ……zzz」。演出のみで作業性能は変更しない。
- **緊急撤退・帰還**：致命傷で撤退、安全になったら通信機で**同じラフィー**を呼び戻せる。傷・有害な健康状態を回復し、**2日間の回復中ペナルティ**。
- **RimTalk（任意、v0.7.15追加）**：新規登場時に日本語・英語・簡体字中国語対応の初期人格を設定。編集済み人格はセーブ・ロードや帰還で上書きしない。設定で無効化可能。既存個体への遡及なし。会話頻度などにも干渉しない。
- **v0.7.24新要素**：飲食アイテム（りんご飴、ウサウサ星のお土産、酸素コーラ、拉菲红酒）と軌道商人「うさうさ星商人」。

## 設定・互換性・既知の制限

### 互換性・既知の事項（2026-11-05）

- **1.6.4871**：NuGetビルドDLLの起動・主要Harmony初期化、加入、顔描画・瞬き、肌色の白色初期化・セーブを確認。
- **1.7.4998 rev1299／Waylith**：NuGetビルドDLLの読み込み、加入、基本描画・瞬き・肌色保存等を確認。**基本動作は合格**、新エンジンの継続更新につき全機能の保証ではない。
- **Intimacy - Friends n' Lovers／Manual Lovin Unofficial**：v0.7.24で競合を改善。
- 任意の睡眠ジョブ表示Harmonyパッチ`LaffeySleepyJobReportV0718`は未実装メソッドへの適用を試み、**警告を出してスキップ**する既知の事象。MOD全体の初期化失敗ではない。
- Performance Analyzer、Camera+、packageId重複等は別MOD／環境の警告として区別する。1.7ログの`otherPawn` deep-save警告も**発生源未特定**（ラフィー起因とは断定していない）。
- 今回の起動ログは殲滅形態、食事アニメーションなどの**全実行経路を網羅していない**。セーブ・ロードと1.7更新時の回帰確認を継続する。
- 公開用`About.xml`には飲食アイテム・商人が「試験要素／未公開」と記載されているが、Workshopのv0.7.24告知では追加要素として掲載済み。**内部説明文の整合は今後の修正事項**。
- Harmony以外の必須MODを増やさずバニラ互換を優先。すべての他MODとの互換性は保証しない。**更新前のセーブバックアップを推奨**。

### Workshop公開運用

- **Workshop ID `3819030381`**で既存投稿を更新、新しい「Face Animation Plus」画像を使用。
- タグは**Mod／1.6／1.7**へ更新。SteamCMDで本体をアップロードし、タグはSteamworksを使ったPowerShellで別途変更。

- 日本語・英語・簡体字中国語の**言語別Workshop説明文**をBBCodeで整備・更新。
