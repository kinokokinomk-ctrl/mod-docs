# Days with Laffey -ラフィーと一緒- [Azur Lane]｜遊び方・機能一覧

[← MODページに戻る](README.md)

## 概要

『アズールレーン』のラフィーをRimWorldに迎え、日常生活や専用装備での戦闘を楽しめるMODです。**v0.7.24「Face Animation Plus」**では独自の表情アニメーションを追加しました。

## 動作環境と導入

| 項目 | 内容 |
| --- | --- |
| RimWorld | **1.6／1.7**（1.7はunstableで動作確認） |
| 必須MOD | **Harmony** |
| 任意連携 | RimTalk、Facial Animation |
| DLC | 不要 |
| 言語 | 日本語・英語・簡体字中国語 |

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3819030381)からサブスクライブできます。Facial AnimationやRimTalkがなくても基本機能は利用できます。RimWorld 1.7はゲーム本体の更新が続くため、完全な互換性は保証できません。

## ラフィーちゃんとの出会い

ゲーム開始後**1～3日目**に加入イベントで登場を試みます。登場しなければ**3日経過後**に通信機かMOD設定から呼び出せます。

専用の顔、2種類の切替可能な髪型、固有の出自・能力・特性を備えています。加入後は通常の入植者と同じように仕事や社交を行います。

## 表情アニメーションと衣装

- 通常の瞬きに加え、**戦闘・睡眠・研究・痛み・ダウン・食事・恋愛**などに応じた専用表情を収録。
- **正面向きで食事中**には、口が動くアニメーションもあります。
- **Facial Animationなしで動作**し、導入している場合も独自の表情を維持します。
- MOD設定から表情アニメーションのON／OFFを切替可能。
- **ラフィー通常衣装**は他の入植者も着用できます。初回加入時には布Tシャツ・布ズボンとともに着用しています。

専用衣装の防御力はバニラの防弾ジャケットを意識した設定で、衣装自体による移動速度低下はありません。耐寒・耐暑・真空耐性にも対応しています。

## 武装と戦闘スキル

| 装備・スキル | 内容 |
| --- | --- |
| **127mm単装砲** | 固定武装。長射程の爆発弾を発射。狩猟中は自動で非爆発弾へ切り替えます。 |
| **533mm五連装魚雷** | 手動で5発の魚雷を扇状に発射します。 |
| **殲滅形態** | 手動で主砲10連射＋魚雷5発を発射。主砲は約0.2秒間隔の高速連射です。 |
| **射線確保** | 高速移動で射撃位置を確保する手動スキル。 |
| **ソロモンの戦神** | 主砲射撃時に確率で発動し、射撃速度を上げる自動能力。 |

127mm砲には淡いピンク色の曳光効果があります。魚雷は壁越しの運用にも配慮し、ラフィーの前方から出現します。

**注意：** 攻撃は必中ではありません。爆発弾や魚雷は味方・建築物を巻き込む場合があります。

## コロニーでの日常

- 専用特性**「おねむ」「マイペース」「仲間思い」**、昼寝、救助・戦闘に応じた固有の心情変化。
- 左下の行動表示は**瞑想・睡眠・食事・研究・掃除・建築・採掘・種まき・収穫**の9種類で、ラフィーらしいひとことに変わります。
- 睡眠時には「ムニャムニャ……zzz」などの言葉が表示されます。行動表示の演出による作業性能の変化はありません。

## 飲食アイテムと軌道商人

v0.7.24から、ほかの入植者も利用できる4種類のアイテムと軌道商人**「うさうさ星商人」**が登場します。

| アイテム | 主な効果 |
| --- | --- |
| **りんご飴** | 娯楽+10%、心情+3（12時間） |
| **ウサウサ星のお土産** | 娯楽+15%、心情+5（24時間） |
| **酸素コーラ** | 娯楽+80%、休息+30%、心情+10・全体作業速度+5%（12時間） |
| **拉菲红酒** | 娯楽+10%、心情+5・意識能力-5%（10時間）、飲酒による酩酊 |

軌道商人とは通信機で取引できます。アイテムによっては製作や通常の交易でも入手できます。詳しい性能・条件はゲーム内の情報も参照してください。

## 緊急撤退と帰還

致命傷を受けるとラフィーは**緊急撤退**します。安全になったら通信機から**同じラフィー**を呼び戻せます。帰還時は傷や有害な健康状態が回復しますが、**2日間の「回復中」ペナルティ**が発生します。

## 任意連携と互換性

**RimTalk：** 導入時、新しく登場したラフィーに3言語対応の初期人格を設定します。プレイヤーが編集した人格はセーブ・ロードや帰還で上書きされず、MOD設定でOFFにできます。既に登場しているラフィーには遡及適用しません。RimTalkの通常の会話頻度にも干渉しません。

**Facial Animation：** 導入していなくてもラフィーの表情が動きます。導入時も独自の表情を維持するよう対応しています。

**その他：** v0.7.24ではIntimacy - Friends n' Lovers、Manual Lovin Unofficialとの互換性を改善しました。ただし、すべてのMODの組み合わせを保証するものではありません。
